Run Notchman free

Set up the Community edition on your computer. About 5 minutes.

Rather not use a terminal? Notchman Pro installs like any app, with nothing to set up.

Download Notchman
1

Install Node.js and git

Notchman Community runs from its source code, so it needs two free tools.

  • Node.js 20 or newer: download the LTS version from nodejs.org and install it with the default options.
  • git: download it from git-scm.com and install it with the default options.
  • git: it comes with the Mac's developer tools. If the check below says it's missing, macOS offers to install it: click Install.

Then open PowerShell (press Start, type PowerShell, press Enter) and check both are there:

Then open Terminal (press ⌘ Space, type Terminal, press Return) and check both are there:

node -v
git --version

You should see v20 or higher and a git version. If it says “not recognized” or “command not found”, close the window and open a new one after installing.

2

Get your free Groq API key

Groq is the AI that writes your TL;DRs. Its key is free.

  1. Open console.groq.com/keys and sign in (Google, GitHub or email).
  2. Click Create API Key, name it Notchman, and click Submit.
  3. Click Copy. The key starts with gsk_ and is shown only once, so keep that tab open until step 3.

Treat the key like a password: don't post it or send it to anyone.

3

Download Notchman and add your key

In the same PowerShellTerminal window, run:

git clone --depth 1 https://github.com/Iamritupatil/notchman-community.git
cd notchman-community
npm install

When it finishes downloading, it asks for your key, right there in the window:

  1. Paste your Groq key: right-click in the window, or press Ctrl+Vpress ⌘V. Nothing appears while you paste. That's on purpose, to keep the key private. Paste once, then press EnterReturn.
  2. When it says Groq key works, it asks for an ElevenLabs key. Just press EnterReturn to skip it: a free voice on your computer reads instead.

Want the natural ElevenLabs voices? Get a key at elevenlabs.io (Settings → API Keys) and add it later with npm run setup.

4

Start Notchman

npm start

The Shiba appears on your screen. Now select any long text, a message, an article or an AI answer, and:

  • press Alt⌥ + T to hear the TL;DR,
  • press Alt⌥ + R to hear every word,
  • or click the Shiba.

The first time you click the Shiba, macOS may ask to allow Accessibility (it copies your selection for you): allow it in System Settings → Privacy & Security → Accessibility.

If npm install didn't ask for your key, npm start asks the first time.

✓

Next time

Open PowerShellTerminal and run:

cd notchman-community

  • Change your keys: npm run setup
  • Get the newest version: git pull, then npm install
  • Start it with Windows: in Notchman's Settings, turn on Open Notchman when you sign in.

If something goes wrong

“npm is not recognized” or “command not found: npm”

Node.js isn't installed, or the window was open before you installed it. Install the LTS version from nodejs.org, then open a new window.

“running scripts is disabled on this system”

PowerShell blocks npm's script by default on some computers. Run this once, answer Y, and try again:

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
“ENOENT: no such file or directory … package.json”

The command ran outside Notchman's folder. Run cd notchman-community first, then try again.

“destination path 'notchman-community' already exists”

You downloaded it before. Go into the folder and update it with cd notchman-community, then git pull and npm install. Or delete the old folder and run step 3 again.

git clone fails or stops with “early EOF”

Download the ZIP instead:

Invoke-WebRequest https://github.com/Iamritupatil/notchman-community/archive/refs/heads/main.zip -OutFile notchman-community.zip
Expand-Archive notchman-community.zip -DestinationPath .
cd notchman-community-main
npm install
curl -L https://github.com/Iamritupatil/notchman-community/archive/refs/heads/main.zip -o notchman-community.zip
unzip notchman-community.zip && cd notchman-community-main
npm install
Nothing shows when I paste my key

That's expected: the key stays hidden so nobody sees it on your screen. Paste once and press EnterReturn. If you pasted twice, run npm run setup and paste once.

“Groq didn't accept that key”

Copy it again from console.groq.com/keys. If you can't see it any more, create a new key there and paste that.

Notchman says it isn't set up yet

In Notchman's folder, run npm run setup and paste your Groq key.
